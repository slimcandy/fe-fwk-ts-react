fe-fwk-ts-react

Render is cheap. The DOM is not.

A notes app built with a TypeScript port of the framework from the book Build a Frontend Web Framework (From Scratch), with React’s names. Every action shows two numbers: how many components ran render(), and how many times the browser’s DOM really changed.

      How it works

      1. Render builds objects

      render() returns a tree of plain objects, the virtual DOM. Building it touches nothing on the page, so a component can render often.

      2. The diff finds what changed

      patchDOM() compares the old tree with the new one. For keyed lists, arraysDiffSequence() works out which items were added, removed or moved.

      3. Only the difference reaches the DOM

      Edit one note and the app renders again, but the other notes see equal props and skip render(). One text node changes.

      Compared with React

      212 tests run on every change: the book’s own test suite, ported to TypeScript, and tests that render the same keyed list with this runtime and with react-dom, apply the same edits, and require the same DOM after each one. Random lists and random edits too.

      DOM writes for each edit of a list of five notes, measured in the tests.
      Edit This runtime React 19
      Add a note11
      Edit a note11
      Delete a note11
      Reverse the list88
      Move the last note to the top 2 8
      Same notes, new objects00

      Moving a node counts as two writes: out and back in. The book’s diff walks the new list and moves the last note into place: one move. React walks left to right and keeps every note that is already in order relative to the last one it placed, so here it moves the other four. Same DOM, different work.

      Run it

      Requires Node.js 22 or newer. The runtime isn’t published to npm: it’s a learning project, so you clone it.

      1. 1

        Clone and install

        git clone https://github.com/slimcandy/fe-fwk-ts-react
cd fe-fwk-ts-react
npm install
      2. 2

        Test it, open this demo

        npm test      # the book's tests and the React comparison
npm run dev   # this page, at http://localhost:5173
      3. 3

        Write a component

        import {
  createApp,
  createComponent,
  createElement,
} from "fe-fwk-ts-react";

const Counter = createComponent({
  state() {
    return { count: 0 };
  },
  render() {
    const { count } = this.state;
    return createElement(
      "button",
      { on: { click: () => this.setState({ count: count + 1 }) } },
      [`Clicked ${count} times`]
    );
  },
});

createApp(Counter).mount(document.body);
